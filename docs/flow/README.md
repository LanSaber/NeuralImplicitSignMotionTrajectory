# Flow Matching Docs

This directory collects the SOKE documents related to continuous flow-matching
generation and its supporting adapter-prior pipeline.

## Entry Points

- `soke_smplx_flow_pipeline.md`: main SMPL-X and latent flow-matching pipeline.
- `latent_flow_hyperparameters.md`: hyperparameter reference for latent flow runs.
- `soke_flow_matching_research.md`: research notes and improvement directions.
- `adapter/soke_content_style_adapter.md`: content-style adapter and soft-arranger training.
- `adapter/soke_soft_word_arranger.md`: soft word arranger design.
- `dataset/flow_training_dataset_format.md`: dataset format used by flow training.
- `evaluation/flow_matching_quantitative_evaluation.md`: quantitative evaluation notes.
- `visualization/flow_visualize_usage.md`: flow sample visualization usage.
