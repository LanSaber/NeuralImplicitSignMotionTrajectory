# Hierarchical Segmental NIAF

## 1. Motivation

The uncertainty-adaptive knot field predicts all frame contexts with one
bidirectional temporal encoder. Its PHOENIX evaluation improves global hand paths
and whole-body DTW, but does not improve PA-normalized finger articulation. The
confidence calibration is also weak. These results suggest that one amortized
whole-sequence prediction is carrying too many responsibilities at once:

- global text-to-motion planning;
- local lexical transitions;
- hand-detail reconstruction; and
- continuous temporal smoothing.

The segmental model keeps the frozen text-conditioned adapter as the global plan,
then predicts a sequence of smaller local trajectory codes. It remains fully
non-oracle at inference.

## 2. Model

Let the adapter scaffold be (s(t)), retrieval evidence be (r(t)), text features
be (c), and articulator-specific uncertainty controls be (q_a(t)). For each
articulator (a), scale (m), and segment (k), the model first pools an
overlapping local scaffold window:

\[
u_{a,m,k} = \operatorname{Pool}_{W_{a,m,k}}
\left[s(t), \dot{s}(t), \ddot{s}(t), r(t), \gamma(t)\right].
\]

The window also exposes its start state, end state, and displacement. A soft
monotonic text context is centered at the normalized position of the segment.

The local codes are generated by a causal recurrent rollout:

\[
h_{a,m,k} = \operatorname{GRU}
\left([u_{a,m,k}, c_{a,m,k}], h_{a,m,k-1}\right),
\qquad
z_{a,m,k} = P_{a,m}(h_{a,m,k}).
\]

Thus, a code is conditioned on its local scaffold interval and all preceding
segment state, but a future scaffold interval cannot rewrite an earlier code.
Unlike frame-autoregressive pose generation, errors are propagated through a
compact latent state rather than through generated joint values.

## 3. Continuous decoding

Segment codes overlap in time. Catmull-Rom interpolation converts each code
sequence into a continuously varying frame code:

\[
z_{a,m}(t) = \operatorname{CubicInterpolate}
\left(\{z_{a,m,k}\}_k, \xi_a(t)\right),
\]

where \(\xi_a(t)\) is the uncertainty-adaptive time coordinate inherited from the
previous field. This provides continuous code values and first derivatives at
interior knots. The existing uncertainty scale weights combine the fine, middle,
and coarse segment codes.

The existing per-articulator SIREN decoders then predict tangent-space residuals:

\[
\hat{x}(t) = s(t) \oplus
D_\theta\left(t, s(t), z(t), r(t), \operatorname{trust}(t),
\operatorname{need}(t)\right),
\]

where \(\oplus\) composes axis-angle residuals with scaffold rotations on
\(SO(3)\). Body, left hand, right hand, jaw, and expression retain their existing
separate residual heads and gates.

## 4. Segment hierarchy

The first PHOENIX configuration uses:

| Articulator | Fine stride | Middle stride | Coarse stride |
|---|---:|---:|---:|
| Body | 8 | 16 | 32 |
| Left hand | 4 | 8 | 16 |
| Right hand | 4 | 8 | 16 |
| Face | 8 | 16 | 32 |

Each segment window is twice its stride, clipped to 8--32 frames. Adjacent windows
therefore overlap by approximately 50%. Retrieval density changes local pooling
and the adaptive interpolation coordinate, while trust and correction need choose
how strongly the fine, middle, and coarse codes contribute.

The model uses the seven cache-compatible adapter evidence channels, including
attention change and lexical mass. Local T5 context is aligned monotonically by
normalized segment position. Full candidate-group attention is not currently
stored in the scaffold cache; adding it would enable explicit word-boundary
segments in a later ablation.

## 5. Losses

All previous objectives remain active:

- endpoint rot6D, geodesic, FK joint, hand-relative, and expression losses;
- tangent residual reconstruction;
- residual velocity, acceleration, and jerk matching;
- FK velocity, acceleration, and jerk matching;
- trust, correction-need, density, scale, and gate supervision; and
- text-only duration prediction.

The segmental path adds losses at frames whose local code intervals meet:

\[
\mathcal{L}_{\text{segment}} =
\lambda_p \mathcal{L}_{p}
+ \lambda_v \mathcal{L}_{v}
+ \lambda_a \mathcal{L}_{a}.
\]

These terms match target pose, velocity, and acceleration around segment
boundaries. They upweight transition quality without penalizing legitimate motion
between ordinary adjacent frames. The default weights are 0.5, 1.0, and 0.25.

```bash

```

The launcher requests four nodes with one GPU per node and enables online W&B
through the existing retrieval-field launcher. It reuses the current adapter and
FK caches.

The standard exporter works unchanged for generated motion and now additionally
saves:

- `segment_boundary_mask`;
- `segment_boundary_stride`;
- `segment_positions_scale*`;
- `segment_codes_scale*`; and
- `segment_mask_scale*`.

## 7. Evaluation plan

Use the same seed-123, 100-sentence manifest as the previous two retrieval-field
experiments. Compare:

1. frozen adapter scaffold;
2. whole-sequence uncertainty-adaptive knot field;
3. hierarchical segmental field;
4. segmental field with recurrence disabled; and
5. segmental field with linear instead of cubic code interpolation.

Report translated and PA-DTW-MPJPE for body and both hands, duration MAE, FK
velocity/acceleration/jerk matching, hand-path ratio, and field wins. The primary
success condition is simultaneous improvement in translated hand trajectories and
PA hand articulation without worsening temporal dynamics.

## 8. Implementation checks

The focused tests cover:

- padded and partial-final segment masks;
- output shapes and valid composed rotations;
- future-window locality;
- propagation of earlier context through recurrent state;
- cubic interpolation continuity;
- boundary-loss selection; and
- finite gradients through the GRU, segment code heads, and uncertainty calibrator.
